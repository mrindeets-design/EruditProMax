## Рекомендации

### Для CI/CD

```yaml
# .github/workflows/test.yml (пример)
test:
  runs-on: ubuntu-latest
  steps:
    - name: Build
      run: go build -o erudit
    - name: Unit tests
      run: go test -short -v
    - name: Race detector
      run: go test -race -short
```

### Для разработки

**Перед коммитом:**
```bash
go fmt ./...
go test -short
```

**Обновление тестов:**
- Не удалять провалившиеся тесты ради "зелёного" результата
- Исправлять тесты, если изменилась логика
- Добавлять регрессионные тесты для каждого бага

**Индексация:**
- Переиндексировать минимум раз в месяц
- После обновления цен/контактов на сайте
- Перед важными периодами (приём абитуриентов)
