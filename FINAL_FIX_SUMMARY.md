# ФИНАЛЬНЫЙ ОТЧЁТ: Исправление ошибки с ценами специальностей

## 🎯 ЗАДАЧА
Исправить воспроизводимую ошибку: бот не находит цены специальностей при вопросах о стоимости обучения.

---

## ❌ ПРОБЛЕМА

### Симптомы
1. **"Подскажи стоимость обучения"** → сообщает только про юриспруденцию, утверждает что других цен нет
2. **"А на дизайн какая стоимость обучения?"** → отвечает "данных нет"
3. **Контрольный факт:** на https://college-nomos.ru/abitur/postupayushchim/ есть цена **139 200 рублей в год** для специальности "Дизайн (54.02.01)"

---

## 🔍 ПРИЧИНА (детальный анализ)

### Основная проблема: switch-case в sourceScore()

**Файл:** `main.go`, строки 505-540 (до исправления)

```go
func sourceScore(source Source, q string) int {
    score := 0
    
    switch {  // ❌ ОШИБКА: switch выполняет только ПЕРВЫЙ matching case
    case isSpecialtyQuestion(q):  // ← Проверяет "специальност", "дизайн"
        if source.Kind == "specialty_detail" { score += 100 }
    case containsAny(q, "стоим", "цен"):  // ← Для вопроса о стоимости
        if source.Kind == "admission" { score += 100 }
        // ❌ НО specialty_detail НЕ получает баллов!
    }
    return score
}
```

### Сценарий ошибки для "Подскажи стоимость обучения":

1. `isSpecialtyQuestion("подскажи стоимость обучения")` = **false** (нет слова "специальност")
2. Switch переходит к `case containsAny(q, "стоим")` = **true**
3. **Выполняется ТОЛЬКО этот case** (switch заканчивается после первого совпадения)
4. Баллы получает **ТОЛЬКО** "Поступающим" (kind="admission"), score=100
5. **Карточки специальностей** (Юриспруденция, Дизайн) получают **0 баллов**
6. `chooseSources()` выбирает топ-3 источника → попадает только "Поступающим"
7. RAG chunking работает с неполным контекстом
8. LLM видит только одну цену и говорит "других цен нет"

## ✅ ИСПРАВЛЕНИЯ

### 1. sourceScore() - убран switch, аккумуляция баллов (строки 505-566)

**Было:**
```go
switch {
case isSpecialtyQuestion(q):
    if source.Kind == "specialty_detail" { score += 100 }
case containsAny(q, "стоим", "цен"):
    if source.Kind == "admission" { score += 100 }
}
```

**Стало:**
```go
// Специальности
if isSpecialtyQuestion(q) {
    if source.Kind == "specialty_detail" { score += 100 }
}

// Поступление, стоимость
if containsAny(q, "стоим", "цен") {
    if source.Kind == "admission" { score += 100 }
    // ИСПРАВЛЕНИЕ: карточки специальностей тоже получают баллы
    if source.Kind == "specialty_detail" { score += 80 }
}
```

**Эффект:** Вопрос "стоимость дизайна" → "Дизайн" получает 100+80=180, "Поступающим" получает 100. Оба попадают в выборку!

---

### 2. chooseSources() - лимит 6 для общих вопросов (строки 664-669)

**Было:** `limit := 3` (всегда)

**Стало:**
```go
limit := 3
if containsAny(q, "стоим", "цен") && !isSpecialtyQuestion(q) {
    limit = 6  // Поступающим + 4 специальности
}
```

---

### 3. chooseSources() - добавление "Поступающим" (строки 614-623)

```go
// Если вопрос о стоимости конкретной специальности,
// добавляем "Поступающим" где есть все цены
if containsAny(q, "стоим", "цен") && len(result) > 0 {
    for _, source := range sources {
        if source.Kind == "admission" {
            result = append(result, source)
            break
        }
    }
}
```
