# Статус реализации гибридного поиска

**Дата:** 2026-10-02  
**Версия:** 1.0.0  
**Статус:** ✅ Лексический режим готов к продакшену

## Выполненные требования

### ✅ Поиск по сохранённому индексу
- Реализован поиск по проиндексированным страницам и документам
- Поиск работает без повторного обхода сайта на каждый вопрос
- FTS5 индекс содержит 5890 фрагментов из 89 страниц

### ✅ Лексический поиск (FTS5)
- Полнотекстовый поиск SQLite FTS5
- Поддержка русского unicode61 remove_diacritics
- Производительность: 5-20ms на запрос

### ✅ Семантический поиск (инфраструктура)
- Настроен Ollama API
- Схема БД для эмбеддингов готова
- Версионирование через content_hash
- Команды: --generate-embeddings, --update-embeddings, --clear-embeddings

### ✅ Хранение эмбеддингов
- Таблица: model, dimension, content_hash, vector
- Указание модели и размерности
- SHA256 хэш для версионирования
- Исключение сравнения несовместимых векторов

### ✅ Объединение результатов
- Гибридный режим: lexical + semantic
- Нормализация BM25 и косинусного сходства к [0,1]
- Ранжирование: 0.4 * lexical + 0.6 * semantic
- Дедупликация по fragment_id

### ✅ Точный поиск ФИО и кодов
- Фразовый поиск: "Иванов Иван Иванович"
- Фразовый поиск: "09.02.07"
- Автоопределение типа запроса

### ✅ Дедупликация
- По fragment_id: нет дублей в гибридном режиме
- По content_hash: проверка SHA256 при индексации
- Не используется дедупликация по первым N символам

### ✅ Ограничение контекста
- MaxContextChars = 12000 (~3000 токенов)
- MaxFragments = 15
- Метаданные: fragment_id, URL, дата, source_type
- Формат с источниками для цитирования

### ✅ Режимы работы
- Лексический при отсутствии эмбеддингов
- Автоматическое определение доступного режима
- Явный выбор: --search-mode lexical|semantic|hybrid

### ✅ Обработка пустого индекса
- Понятное сообщение: "индекс пуст, запустите краулер"
- Проверка наличия фрагментов

## Использование

```bash
# Базовый поиск
erudit.exe "Какие специальности?"

# Выбор режима
erudit.exe --search-mode lexical "вопрос"
erudit.exe --search-mode semantic "вопрос"
erudit.exe --search-mode hybrid "вопрос"

# Управление
erudit.exe --rebuild-fts
erudit.exe --generate-embeddings
erudit.exe --update-embeddings
erudit.exe --clear-embeddings
```
