# Диагностика точности ответов Erudit

## Характеристики системы
- CPU: AMD Ryzen 7 3700X (8 ядер)
- RAM: ~16 GB
- GPU: NVIDIA GeForce RTX 2060 SUPER (4 GB VRAM)
- OS: Windows 11

## Обнаруженные критические проблемы

### 1. Отсутствие истории диалога
Каждый запрос обрабатывается изолированно. Уточняющие вопросы не работают.

### 2. Нет извлечения документов (PDF/DOC)
Важная информация (стоимость, правила поступления) в документах игнорируется.

### 3. Жесткая категоризация источников
Релевантная информация может не попасть в контекст из-за ограничений по типу.

### 4. Обрезка контекста без учета структуры
24000 символов обрезаются посимвольно, таблицы и списки разрываются.

### 5. Нет ссылок на источники в ответе
API возвращает только текст, проверить информацию невозможно.

### 6. Модель 3B слишком мала
При доступных 4 GB VRAM можно использовать 7B-9B модели.

### 7. Малый контекст (8K токенов)
Недостаточно для документов со специальностями и расписаниями.

### 8. Отсутствие дат публикации
Бот не может отвечать на вопросы про актуальность ("новости за декабрь").

## Рекомендуемая модель
**qwen2.5:7b-instruct** — лучшее соотношение качество/ресурсы для RTX 2060 Super.
