## ВЫЯВЛЕННЫЕ ПРОБЛЕМЫ

### 1. Загрязнённый поисковый запрос после уточнения
**Симптом:** "Привет, подскажи стоимость" → уточнение → "Дизайн интересует" → бот перечисляет программы вместо цены

**Причина:** 
- `intent.go:300` конкатенировал: `"Привет, подскажи стоимость обучения по специальности дизайн интересует"`
- `search.go:39` использовал этот текст для поиска без очистки

**Исправление:**
- Добавлена очистка от приветствий при формировании вопроса (intent.go:318-325)
- Создана функция `buildOptimalSearchText()` для чистого поискового запроса (search.go:73-103)

### 2. Противоречивые инструкции LLM
**Симптом:** "Контакты?" → только телефон, "Где колледж?" → "В Воронеже"

**Причина:** Промпт требовал "КОРОТКО, 2-3 предложения"

**Исправление:**
- Убрано "КОРОТКО", заменено на "ПОЛНО и ПО СУЩЕСТВУ"
- Добавлен раздел "ПОЛНОТА ОТВЕТА" с явными требованиями
- Добавлены примеры для контактов и адреса (main.go:1417-1510)

### 3. Отсутствие сопоставления специальностей
**Симптом:** Путаница между "дизайн", "дизайн интерьера", разными специальностями

**Исправление:** Добавлен раздел СПЕЦИАЛЬНОСТИ с явным сопоставлением:
- "дизайнер"/"дизайн" → 54.02.01 Дизайн (по отраслям)
- "дизайн интерьера" → профессия, связанная с Дизайн
- 4 специальности перечислены явно
