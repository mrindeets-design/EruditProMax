# Чеклист: проверка данных FAQ

## 🎯 Цель
Проверить корректность информации из раздела FAQ на сайте колледжа и в базе данных бота.

---

## 📋 Шаги проверки

### 1. Проверка данных в базе данных

**Команда для проверки:**
```bash
# Установите DB Browser for SQLite или используйте sqlite3
sqlite3 erudit.db
```

**SQL запросы:**
```sql
-- Показать все источники FAQ
SELECT id, url, title, LENGTH(text) as text_length, last_updated 
FROM sources 
WHERE url LIKE '%faq%' 
ORDER BY url;

-- Показать содержимое конкретного источника
SELECT text 
FROM sources 
WHERE url LIKE '%faq%' 
LIMIT 1;

-- Показать все chunks из FAQ
SELECT id, source_id, LENGTH(text) as chunk_length, text 
FROM chunks 
WHERE source_id IN (SELECT id FROM sources WHERE url LIKE '%faq%')
LIMIT 10;
```


### Вариант 2: Вручную через SQL

```sql
-- Удалить старые данные FAQ
DELETE FROM chunks WHERE source_id IN (SELECT id FROM sources WHERE url LIKE '%faq%');
DELETE FROM sources WHERE url LIKE '%faq%';

-- После этого запустить crawler для переиндексации
```

## 🚨 Красные флаги (что точно нужно исправить)

1. **Противоречия в ценах** - разные цены для одной специальности
2. **"Не нашёл информации" + даёт ответ** - логическая ошибка
3. **Устаревшие контакты** - старый номер телефона/email
4. **Неправильные коды специальностей** - путаница между 54.02.01 и 40.02.04
5. **Отсутствие источников** - бот даёт ответ без ссылок на источники
