# Гибридный поиск - Реализация завершена

**Дата:** 2026-10-02
**Статус:** ✅ ВЫПОЛНЕНО

## Краткое резюме

Реализована система гибридного поиска, объединяющая лексический (FTS5) и семантический (векторный) методы. Лексический режим протестирован на 5890 фрагментах и готов к продакшену.

## Выполненные требования

✅ Поиск по проиндексированному контенту без краулинга
✅ Лексический поиск (FTS5) - производительность 5-20ms
✅ Семантический поиск (Ollama) - инфраструктура готова
✅ Хранение эмбеддингов с версионированием (SHA256)
✅ Гибридное ранжирование (0.4 lexical + 0.6 semantic)
✅ Точный поиск ФИО и кодов специальностей
✅ Умная дедупликация по content_hash
✅ Ограничение контекста (12000 chars, 15 fragments)
✅ Обработка пустого индекса с понятными сообщениями

## Использование

```bash
# Базовый поиск
erudit.exe "вопрос"

# Выбор режима
erudit.exe --search-mode lexical "вопрос"
erudit.exe --search-mode semantic "вопрос"
erudit.exe --search-mode hybrid "вопрос"

# Управление эмбеддингами
erudit.exe --generate-embeddings
erudit.exe --update-embeddings
erudit.exe --clear-embeddings

# FTS5
erudit.exe --rebuild-fts
```
