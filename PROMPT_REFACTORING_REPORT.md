# Отчёт: Удаление жёстко прописанных данных из системного промпта

**Дата:** 02.10.2026  
**Задача:** Убрать изменяемые сведения о колледже из системного промпта и получать их из индексированных источников

---

## Проблема

В системном промпте были жёстко прописаны изменяемые факты:

### 1. Цены обучения
```
СТОИМОСТЬ (КРИТИЧНО):
- 54.02.01 Дизайн = 139 200 ₽
- 40.02.04 Юриспруденция = 80 000 ₽
```

### 2. Информация об общежитии
```
ОБЩЕЖИТИЕ (КРИТИЧНО):
❌ У колледжа «Номос» НЕТ общежития
```

### 3. Режим работы
```
РЕЖИМ РАБОТЫ (КРИТИЧНО):
- Понедельник-Пятница: 14:00-19:00
- Суббота-Воскресенье: выходные
- Телефон: +7 (473) 271-35-36
- Адрес: г. Воронеж, ул. Пятницкого, 67
```

### 4. Имя директора
```
Q: "Кто директор?"
✅ "Директор колледжа — Колесникова Полина Владимировна."
```

### 5. Фиксированное приветствие в answer.go
```go
DirectReply: "Здравствуйте! Я Эрудит — помощник Воронежского колледжа «Номос». 
Могу рассказать о поступлении, специальностях, стоимости обучения, преподавателях..."
```

---

## Риски такого подхода

1. **Конфликт с актуальными данными:** Цены меняются ежегодно, директор может смениться, режим работы может измениться
2. **Устаревание промпта:** При обновлении данных на сайте придётся вручную править промпт
3. **Некорректная работа RAG:** Жёсткие значения могут перевешивать актуальные данные из индекса
4. **Сложность поддержки:** Факты дублируются в коде, промпте и базе данных

## Новое поведение системы

### Сценарий 1: Вопрос о стоимости
**Вопрос:** "Какая стоимость обучения на дизайне?"

**Старое поведение:**
- Промпт содержал: "54.02.01 Дизайн = 139 200 ₽"
- LLM мог вернуть жёсткую цену даже при её отсутствии в контексте

**Новое поведение:**
- LLM ищет стоимость ТОЛЬКО в контексте
- Указывает код специальности и учебный год, если они есть
- При отсутствии данных: "Актуальную стоимость уточните в приёмной комиссии"

### Сценарий 2: Конфликт цен
**Ситуация:** В индексе два документа с разными ценами для одной специальности

**Старое поведение:**
- LLM мог выбрать жёсткую цену из промпта или произвольную из контекста

**Новое поведение:**
- LLM сообщит: "Нашёл разную информацию. Уточните актуальную стоимость..."

### Сценарий 3: Вопрос о директоре
**Вопрос:** "Кто директор?"

**Старое поведение:**
- Промпт содержал: "Директор — Колесникова Полина Владимировна"
- Риск выдачи устаревшего имени

**Новое поведение:**
- LLM ищет ФИО директора ТОЛЬКО в контексте из /sveden/employees/
- Если нет: "Этой информации нет на сайте. Уточните в приёмной комиссии"

### Сценарий 4: Учёт учебного года
**Вопрос:** "Сколько стоит обучение на юриста?"

**Старое поведение:**
- Ответ: "80 000 рублей в год" (без указания периода)

**Новое поведение:**
- Если в контексте: "Обучение... стоит 80 000 рублей (2025-2026 учебный год)"
- Учебный год явно упоминается

**Входные данные:**

**Ожидаемый ответ:**

```
**Ожидаемый ответ:**
```
Нашёл разную информацию о стоимости. Уточните актуальную стоимость 
в приёмной комиссии: +7 (473) 271-35-36
```

#### Тест 3: Отсутствие информации

```
**Ожидаемый ответ:**
```
Актуальную стоимость обучения уточните в приёмной комиссии: +7 (473) 271-35-36
```

#### Тест 4: История не является источником
**Входные данные:**
```

  Bot: "150 000 рублей" (старый неверный ответ)
  
Новый вопрос: "А на юриспруденции?"
Контекст: "40.02.04 Юриспруденция — 85 000 руб/год"
```
**Ожидаемый ответ:**
```
Обучение на специальности 40.02.04 Юриспруденция стоит 85 000 рублей в год.
```
**НЕ должно быть:** упоминаний 150 000 из истории
