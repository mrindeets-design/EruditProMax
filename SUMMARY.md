# ИТОГОВАЯ СВОДКА - 13.10.2026

## ✅ ВЫПОЛНЕНО

### 1. Добавлено поле `raw_html` в таблицу `pages`
- Схема БД обновлена (миграция версии 2 → 3)
- Поле сохраняет исходный HTML для последующей переиндексации
- Краулер автоматически заполняет это поле при обходе

### 2. Краулер сохраняет HTML
**Файл:** `crawler.go`
- При успешном скачивании страницы HTML сохраняется в `raw_html`
- Обработка кодировок: UTF-8, windows-1251, автодетекция
- Валидация UTF-8 перед сохранением

### 3. Команда `reindex` для обогащённой индексации
**Файл:** `reindex.go` (новый)
- Обрабатывает все страницы с `raw_html IS NOT NULL`
- Парсит HTML с помощью goquery
- Извлекает структурированные данные с метаданными
- Создаёт обогащённые фрагменты

### 4. Извлечение метаданных
**Реализовано в:** `reindex.go` → `extractEnrichedFragments()`

#### Извлекаемые данные:
- **section_title** - заголовок текущей секции (H1-H6)
- **parent_titles** - JSON-массив иерархии заголовков
- **specialty_code** - коды специальностей (54.02.01, 44.02.02, 40.02.04)
- **academic_year** - учебный год (2026, 2027)
- **document_type** - тип документа (учебный план, программа, положение)
- **metadata_quality** - оценка качества (low, medium, high)

#### Алгоритмы извлечения:

**Иерархия заголовков:**
```go
// Обход DOM, построение breadcrumbs
["Добро пожаловать", "Новости", "День учителя в «Номосе»"]
```

**Коды специальностей:**
- Регулярные выражения: `54\.02\.01`, `44\.02\.02`, `40\.02\.04`
- Поиск в тексте, заголовках, ссылках
- Сопоставление с названиями: "дизайн" → 54.02.01

**Учебные годы:**
- Паттерны: `2026`, `2026-2027`, `2026/2027`
- Извлечение из текста документов

### 5. Сохранение обогащённых фрагментов
**Файл:** `reindex.go` → `saveEnrichedFragment()`
- Удаляет старые фрагменты страницы
- Вставляет новые с метаданными
- Транзакционность операций

### 6. Проверочные скрипты
Созданы утилиты для валидации:

| Скрипт | Назначение |
|--------|------------|
| `verify_raw.go` | Проверка наличия raw_html |
| `check_fragments.go` | Статистика фрагментов |
| `check_specialty_fragments.go` | Фрагменты по специальностям |
| `check_hierarchy.go` | Иерархия заголовков |
| `final_stats.go` | Полная статистика БД |
