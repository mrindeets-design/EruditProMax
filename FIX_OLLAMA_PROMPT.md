# ИСПРАВЛЕНИЕ ПРОБЛЕМ С ОТВЕТАМИ OLLAMA

## Дата: 27.09.2026

## Выявленные проблемы

### 1. Проблема со стоимостью
**Симптом**: Система находит данные (11770 символов), но LLM отвечает "не нашел данных", при этом называет правильные цены.

**Причина**: Противоречивый и слишком сложный промпт. Модель путается между инструкциями:
- "Если факта нет в контексте, так и скажи" (правило 4)
- "Если точного ответа в контексте нет..." (последнее правило)

Это заставляло модель говорить "не нашел", даже когда данные были в контексте.

### 2. Проблема с педагогами
**Симптом**: Система находит 6 фрагментов (10586 символов), но не отвечает правильно на вопрос про педагогов.

**Причина**: Нечеткие инструкции в промпте для раздела преподавателей.

### 3. Упоминание несуществующих специальностей
**Симптом**: LLM галлюцинирует и добавляет информацию о специальностях, которых нет в контексте.

**Причина**: Недостаточно строгие инструкции о том, что нельзя придумывать факты.

## Внесенные изменения

### 1. Упрощение системного промпта (`buildAnswerInstructions`)

**Было**: 21 правило в виде нумерованного списка с противоречиями

**Стало**: Короткий и четкий промпт с разделами:

```
ГЛАВНОЕ ПРАВИЛО: Отвечай на вопрос, используя ТОЛЬКО информацию из переданного контекста.

КАК ОПРЕДЕЛИТЬ, ЕСТЬ ЛИ ОТВЕТ:
- Если в контексте явно написана информация — отвечай уверенно и прямо
- Если информации нет — скажи: "На предоставленных материалах колледжа я не нашёл информации"
- НЕ ГОВОРИ "не нашел", если информация реально есть в контексте!

СТОИМОСТЬ ОБУЧЕНИЯ (КРИТИЧЕСКИ ВАЖНО):
- 54.02.01 Дизайн = 139 200 рублей
- 40.02.04 Юриспруденция = 80 000 рублей
- ВСЕГДА смотри на КОД специальности рядом с ценой
- НЕ ПУТАЙ цены разных специальностей

ПРЕПОДАВАТЕЛИ:
- Если в контексте есть список — перечисли их ФИО
- Указывай предметы только если они явно написаны
- Не придумывай преподавателей

СТИЛЬ ОТВЕТА:
- Отвечай сразу по делу, без вступлений
- Не используй Markdown
- Не показывай URL
- Не придумывай факты
```

### 2. Улучшение пользовательского промпта

**Было**:
```
ВОПРОС ПОЛЬЗОВАТЕЛЯ:\n[вопрос]
КОНТЕКСТ С САЙТА:\n[контекст]
Сформируй один законченный ответ пользователю. Не добавляй ничего, чего нет в контексте.
```

**Стало**:
```
ВОПРОС ПОЛЬЗОВАТЕЛЯ:\n[вопрос]
=== КОНТЕКСТ С САЙТА КОЛЛЕДЖА ===\n[контекст]
=== ТВОЯ ЗАДАЧА ===
Прочитай контекст и ответь на вопрос. Используй ТОЛЬКО информацию из контекста. 
Если есть ответ — говори уверенно. Если нет — скажи что не нашел.
```

### 3. Упрощение дополнительных правил

**Для новостей**:
- Было: 5 подробных правил
- Стало: 3 простых пункта

**Для преподавателей**:
- Было: 3 правила с примерами
- Стало: 3 четких пункта с акцентом на "не придумывай"

**Для специальностей**:
- Было: Подробные инструкции для каждого случая
- Стало: Короткие директивы

### 4. Удалено противоречивое финальное правило

**Было**:
```
Если точного ответа в контексте нет, ответь: «На предоставленных материалах 
колледжа я не нашёл точной информации по этому вопросу». Не пытайся догадаться.
```

**Стало**: Удалено, так как уже есть в основном разделе

## Ключевые улучшения

1. **Однозначность**: Четко указано, когда говорить "не нашел", а когда отвечать уверенно
2. **Краткость**: Промпт сокращен с ~30 правил до ~15 четких директив
3. **Приоритеты**: Самые важные вещи (стоимость, не придумывать) вынесены в начало
4. **Структурированность**: Разделы четко отделены, легко читать
5. **Конкретность**: Указаны конкретные цены специальностей в промпте

## Ожидаемый результат

После этих изменений:
- ✅ Система будет отвечать уверенно, когда данные есть в контексте
- ✅ Не будет путать цены разных специальностей
- ✅ Правильно перечислит педагогов из контекста
- ✅ Перестанет галлюцинировать несуществующие специальности
- ✅ Ответы станут более четкими и по делу

## Тестирование

Рекомендуется протестировать следующие вопросы:

1. **Стоимость**: "Какая стоимость обучения на дизайне?" → Должен ответить "139 200 рублей" без фразы "не нашел"
2. **Педагоги**: "Какие есть педагоги в колледже?" → Должен перечислить ФИО из контекста
3. **Специальности**: "Какие специальности есть?" → Должен назвать только 4 реальные (не придумывать)
4. **Отсутствующая информация**: "Есть ли в колледже бассейн?" → Должен сказать "не нашел информации"
