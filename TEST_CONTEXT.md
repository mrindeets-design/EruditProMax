# Тестирование контекстного диалога

Запуск теста диалога:
```bash
.\erudit_context_fixed.exe
```

## Тестовый сценарий:

1. Вопрос: "Привет, подскажи мне стоимость обучения"
   Ожидаемый ответ: Уточнение о специальности

2. Вопрос: "на дизайн"
   Ожидаемый ответ: Стоимость обучения по дизайну (139 200 рублей)

## Проблемы которые должны быть исправлены:

1. ✅ Система не должна говорить "не нашёл", а затем давать ответ
2. ✅ При уточнении специальности система должна помнить исходный вопрос
3. ✅ Ответ не должен требовать повторного уточнения после того, как пользователь его предоставил

## Изменения в коде:

### answer.go (StreamAnswer)
- Добавлена проверка `intent.Type != "clarification"` при IsAmbiguous
- Теперь не запрашивает повторное уточнение при ответе на уточняющий вопрос
- Сохраняет контекст диалога для будущих ответов

### intent.go (resolveAnaphora)
- Исправлен вызов `extractEntities(q, intent, context)` вместо `&intent`
- Правильно извлекает специальность из короткого ответа пользователя

### main.go (промпты Ollama)
- Усилено указание: "Если в контексте есть ответ — отвечай ПРЯМО и УВЕРЕННО, БЕЗ фразы 'не нашёл'"
- Улучшена инструкция для избежания противоречий
