# ИТОГОВЫЕ ИСПРАВЛЕНИЯ - 27.09.2026

## Выявленные проблемы

### 1. Стоимость обучения
**Проблема**: Система отвечала "не нашел информации", хотя данные были в контексте.
**Корневая причина**: 
- Сложный и противоречивый промпт (21 правило)
- Информация о ценах не загружалась со страниц сайта
- Страница `/sveden/paid_edu/` (Платные услуги) не была добавлена в источники

### 2. Преподаватели  
**Проблема**: Система не отвечала на вопрос "перечисли преподавателей"
**Корневая причина**: 
- Функция `detectTopic` не распознавала слово "преподавателей" (только "преподаватель")
- Вопрос определялся как `topic=general` вместо `topic=staff`
- Из-за этого не загружались страницы с преподавателями

### 3. Галлюцинации
**Проблема**: LLM упоминала несуществующие специальности
**Корневая причина**: Недостаточно строгие инструкции в промпте

## Тестирование

Протестируйте следующие вопросы:

1. **"Какая стоимость обучения на дизайнера?"**
   - Должен загрузить страницу `/sveden/paid_edu/` или `/abitur/specialties/`
   - В логах должны быть `HIGH RELEVANCE FRAGMENT` с информацией о цене
   - Ответ должен содержать конкретную цену БЕЗ фразы "не нашел"

2. **"Перечисли преподавателей"**
   - В логах должно быть `INTENT: topic=staff` (НЕ `general`)
   - Должны загрузиться страницы `/teachers/` и `/teachers/?PAGEN_2=2`
   - Ответ должен содержать список ФИО преподавателей

3. **"Какие специальности?"**
   - Должен назвать только 4 реальные специальности
   - Не должен выдумывать несуществующие

4. **"А сколько стоит на юриста?"**
   - Не должен путать с ценой дизайна
   - Должен назвать правильную цену юриспруденции
