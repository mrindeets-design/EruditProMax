# Тестирование улучшений системы Q&A

Дата: 2026-10-01

## Изменения

### 1. Улучшен промпт для Ollama
**Проблема:** Система говорила "не нашёл информации", а затем всё равно давала ответ - противоречие.

**Решение:**
- Добавлено явное указание: "НЕ говори 'не нашёл', а потом давай ответ — это противоречие!"
- Усилена инструкция: "Если информация есть ХОТЯ БЫ в одном фрагменте → отвечай уверенно"
- Обновлён промпт во всех трёх функциях: `askOllama`, `streamFromOllama`, `streamOllama`

### 2. Расширен словарь синонимов
Добавлены новые синонимы для лучшего поиска:
- `"директор"`: {"руководитель", "глава", "директорат", "управление"}
- `"факультет"`: {"специальность", "направление", "отделение", "кафедра"}
- Обновлено `"специальность"`: добавлены {"факультет", "кафедра"}

## Файлы изменены
- `main.go`: улучшены инструкции и промпты для модели
- `search.go`: расширен словарь синонимов
