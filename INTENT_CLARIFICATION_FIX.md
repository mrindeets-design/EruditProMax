# Исправление обработки намерений и уточнений

## Дата
2026-02-10

## Проблемы

1. **Приветствие с вопросом**: "Здравствуйте, какие документы нужны?" распознавалось как простое greeting, вопрос игнорировался
2. **Потеря контекста при уточнении**: Ответ "Дизайн" на уточнение специальности терял связь с исходным вопросом о стоимости
3. **Перезапись темы**: Восстановленная тема перезаписывалась повторным вызовом detectTopic для короткого ответа
4. **Обрезание названий**: "юриспруденция" сохранялась как "юриспруденц"

## Решение

### 1. Улучшена функция isGreeting (intent.go)
```go
// Теперь проверяет наличие вопросительных слов и знака вопроса
// "Здравствуйте, какие документы?" → НЕ приветствие, а вопрос
// "Здравствуйте" → приветствие
```

### 2. Приоритетная обработка незавершенных вопросов (resolveAnaphora)
```go
// Работает НЕЗАВИСИМО от наличия History
if context.PendingQuestion != "" && context.ExpectedParameter != "" {
    // Проверяем: короткий ответ или новый вопрос
    isNewQuestion := (wordCount > 5 && hasQuestionMark) || hasExplicitQuestion
    
    if isShortAnswer && !isNewQuestion {
        // Восстанавливаем тему из PartialInfo
        // Очищаем ожидание после разрешения
        return
    }
}
```

### 3. Защита восстановленной темы (UnderstandIntent)
```go
// resolveAnaphora вызывается ДО detectTopic
topicRestoredFromClarification := false
if intent.Type == "clarification" && intent.Topic != "" {
    topicRestoredFromClarification = true
}

// detectTopic не перезаписывает восстановленную тему
if !topicRestoredFromClarification {
    intent.Topic = detectTopic(q, context)
}
```

### 4. Полные названия специальностей (extractEntities)
```go
specialtyPatterns := map[string]struct{
    name string
    code string
}{
    "юриспруденц": {"юриспруденция", "40.02.04"},
    "дизайн":      {"дизайн", "54.02.01"},
    // ...
}
// Сохраняем полное название, а не паттерн
```

### 5. Очистка ожидания при смене темы
```go
if isTopicChange(q, context) {
    // Очищаем PendingQuestion, ExpectedParameter, PartialInfo
    context.PendingQuestion = ""
    context.ExpectedParameter = ""
    context.PartialInfo = nil
}
```

### 6. Улучшено определение смены темы (isTopicChange)
```go
// Теперь работает без требования History
// "Другой вопрос: расскажите про практику" → topic_change
```
