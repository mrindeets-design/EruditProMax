**1. Список специальностей**
```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"question": "Какие специальности есть?"}'
```
Ожидание: Только список из 4 специальностей (название + код)
НЕ должно быть: стоимости, директора, преподавателей

**2. Стоимость дизайна**
```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"question": "Стоимость дизайна?"}'
```
Ожидание: 139 200 рублей в год

**3. Директор**
```bash

  -d '{"question": "Кто директор?"}'
```
Ожидание: Колесникова Полина Владимировна

**4. Диалоговый контекст**
```
Вопрос 1: "Какая стоимость на дизайне?"
```

Ожидание: НЕ путать цены между специальностями
