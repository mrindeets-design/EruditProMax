# ИСПРАВЛЕНИЕ ОШИБКИ: Бот не находит цены специальностей

## Проблема
- "Подскажи стоимость обучения" → сообщает только про юриспруденцию
- "А на дизайн какая стоимость обучения?" → "данных нет"
- Факт: на https://college-nomos.ru/abitur/postupayushchim/ есть 139 200 руб для дизайна

## Причина (найдена)
**Switch-case в sourceScore() выбирал только ПЕРВЫЙ matching case:**
- Вопрос "стоимость обучения" → `isSpecialtyQuestion()=false` → переходил к `case "стоим"` → выбирал **ТОЛЬКО** "admission" (Поступающим)
- **Карточки специальностей** (kind="specialty_detail") НЕ попадали в выборку
- RAG chunking работал только с фрагментами из "Поступающим", где могла быть только одна цена

## Исправления (внесены в main.go)

### 1. sourceScore() - убран switch, используется аккумуляция (строки 505-566)
```go
// БЫЛО: switch { case ... } - только первое совпадение
// СТАЛО: if ... if ... if - накопление баллов

// Добавлено:
if containsAny(q, "стоим", "цен") && source.Kind == "specialty_detail" {
    score += 80  // Карточки специальностей тоже получают баллы при вопросах о цене
}
```

### 2. chooseSources() - увеличен лимит для вопросов о стоимости (строки 664-669)
```go
// Для общих вопросов о стоимости увеличиваем лимит с 3 до 6,
// чтобы захватить и "Поступающим" и все 4 карточки специальностей
limit := 3
if containsAny(q, "стоим", "цен") && !isSpecialtyQuestion(q) {
    limit = 6
}
```

### 3. chooseSources() - добавление "Поступающим" к конкретной специальности (строки 614-623)
```go
// Если вопрос о стоимости конкретной специальности (например "дизайн"),
// добавляем страницу "Поступающим" где есть все цены
if containsAny(q, "стоим", "цен") && len(result) > 0 {
    for _, source := range sources {
        if source.Kind == "admission" {
            result = append(result, source)
            break
        }
    }
}
```

### 4. questionTerms() - улучшен поиск ключевых слов (строки 720-741)
```go
// БЫЛО: минимум 4 символа, "специальность"/"новости" в стоп-словах
// СТАЛО: минимум 3 символа (для "цен", "год"), убраны важные слова из стоп-слов
```
