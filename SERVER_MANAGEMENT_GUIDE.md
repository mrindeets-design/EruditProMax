# Управление сервером Erudit

## 📜 Скрипты управления

Созданы PowerShell скрипты для удобного управления сервером:

### 1. `start_server.ps1` - Запуск сервера
```powershell
.\start_server.ps1
```
**Функции:**
- Проверка наличия бинарника
- Остановка старых процессов
- Освобождение порта 3000
- Запуск сервера
- Проверка доступности API

### 2. `stop_server.ps1` - Остановка сервера
```powershell
.\stop_server.ps1
```
**Функции:**
- Поиск всех процессов erudit
- Корректная остановка процессов
- Проверка полной остановки

### 3. `restart_server.ps1` - Перезапуск сервера
```powershell
.\restart_server.ps1
```
**Функции:**
- Остановка текущего сервера
- Запуск нового экземпляра

### 4. `rebuild.ps1` - Пересборка и перезапуск
```powershell
.\rebuild.ps1
```
**Функции:**
- Остановка сервера
- Удаление старого бинарника
- Сборка нового бинарника (go build)
- Запуск нового сервера
- Проверка размера и даты бинарника

### 5. `status.ps1` - Проверка статуса
```powershell
.\status.ps1
```
**Функции:**
- Проверка запущенных процессов (PID, uptime, memory)
- Проверка занятости порта 3000
- Проверка доступности API
- Проверка наличия бинарника
- Проверка fallback_data.json

---

## 🚀 Быстрый старт

### Первый запуск:
```powershell
.\rebuild.ps1
```

### Обычная работа:
```powershell
# Проверить статус
.\status.ps1

# Запустить
.\start_server.ps1

# Остановить
.\stop_server.ps1

# Перезапустить
.\restart_server.ps1
```

### После изменения кода:
```powershell
.\rebuild.ps1
```

## 🔧 Решенные проблемы

### 1. Множественные процессы
**Проблема:** Накапливались запущенные процессы  
**Решение:** Скрипты автоматически останавливают все старые процессы перед запуском

### 2. Занятый порт
**Проблема:** Порт 3000 оставался занятым после остановки  
**Решение:** Автоматическая проверка и освобождение порта

### 3. Старые бинарники
**Проблема:** Накапливалось много версий бинарников  
**Решение:** Удалены все старые версии, rebuild.ps1 удаляет старый перед сборкой

### 4. Неясный статус
**Проблема:** Непонятно, запущен ли сервер  
**Решение:** status.ps1 показывает полную информацию

## ⚡ Рекомендации

1. **Всегда используйте скрипты** вместо ручного запуска
2. **Проверяйте статус** перед внесением изменений
3. **Используйте rebuild.ps1** после изменения кода
4. **Регулярно проверяйте логи** для выявления проблем

---

## 🛡️ Безопасность

- Скрипты используют `-Force` для надежной остановки процессов
- Автоматическая проверка перед запуском предотвращает конфликты
- Все скрипты с обработкой ошибок и информативным выводом
