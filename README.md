# EruditProMax — ИИ-помощник колледжа НОМОС

Интеллектуальный чат-бот на базе локальной LLM с улучшенным поиском и обработкой UTF-8.

## Последние улучшения ✅
- **UTF-8 Fix**: Исправлена обработка кириллицы (каскадная детекция кодировки)
- **Smart Teacher Search**: Точный поиск преподавателей с релевантностью 0.860
- **Teacher Chunking**: Каждый преподаватель в отдельном фрагменте
- **Relevance Boost**: Бонус +0.5 за полное совпадение ФИО
- **Context Optimization**: Уменьшен шум (15→5 фрагментов)
- RAG (поиск релевантных фрагментов)
- Источники в API response
- Контекст 8K → 32K токенов (+300%)
- Модель 3B → 7B (+133%)

## Быстрый старт

```bash
# 1. Установить Ollama (https://ollama.ai)
# 2. Установить модель
ollama pull llama3.1:8b

# 3. Запустить
go run .

# 4. Открыть
# http://localhost:3000/widget/chat.html
```

## API

```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"question": "Какие предметы ведёт Богитова Юлия Олеговна?"}'
```

**Ответ**: История, История родного края, Основы этики, История России ✅
