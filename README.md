# Erudit — ИИ-помощник колледжа НОМОС

Интеллектуальный чат-бот на базе локальной LLM (Ollama) с RAG-поиском по индексированному контенту сайта колледжа.

## Возможности

- **RAG (Retrieval-Augmented Generation)**: Поиск релевантных фрагментов из индексированного контента
- **Обогащённые метаданные**: Иерархия заголовков, коды специальностей, учебные годы
- **Управление диалогом**: Поддержка контекста, уточнений, истории сообщений
- **Кеширование**: Умное кеширование ответов с инвалидацией при обновлении источников
- **UTF-8**: Корректная обработка кириллицы (каскадная детекция кодировки)
- **Streaming**: Потоковая передача ответов для улучшенного UX
- **Управление сессиями**: Изолированные диалоги для разных пользователей
- **Веб-виджет**: Готовый чат-виджет для встраивания на сайт

## Требования

- **Go**: 1.21 или новее
- **Ollama**: установлен и запущен локально
- **LLM модель**: llama3.1:8b или llama3.2:3b
- **RAM**: ~8 GB
- **VRAM**: ~5 GB (для 8B модели)
- **SQLite**: встроенная БД для индекса и кеша

## Установка

### 1. Установить Ollama

```bash
# Windows/Mac/Linux - скачать с https://ollama.ai
# Установить модель
ollama pull llama3.1:8b
```

### 2. Клонировать и собрать проект

```bash
git clone <repository-url>
cd erudit
go build -o erudit.exe
```

### 3. Конфигурация (опционально)

Создайте `.env` файл:

```env
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b
BASE_URL=https://college-nomos.ru
DB_PATH=./data/erudit.db
PORT=3000
MAX_CONCURRENT_REQUESTS=5
```

## Запуск

### Индексация сайта

Перед первым запуском проиндексируйте контент:

```bash
# Windows - краулинг с сохранением HTML
.\erudit.exe crawl

# Переиндексация с обогащёнными метаданными
.\erudit.exe reindex

# Проверка статистики
go run final_stats.go
```

Параметры краулинга:
- `-crawl-url <url>` — начальный URL (по умолчанию: https://college-nomos.ru)
- `-crawl-depth <N>` — глубина обхода (по умолчанию: 3)
- `-crawl-workers <N>` — параллельные воркеры (по умолчанию: 3)
- `-crawl-pages <N>` — максимум страниц (по умолчанию: 200)

### Запуск сервера

```bash
.\erudit.exe
# Сервер: http://localhost:3000
# Виджет: http://localhost:3000/widget/chat.html
```

## API

### POST /api/chat

**Запрос:**
```json
{
  "question": "Какие предметы ведёт Богитова Юлия Олеговна?",
  "session_id": "uuid-v4-string",
  "stream": false
}
```

**Ответ:**
```json
{
  "answer": "Богитова Юлия Олеговна ведёт: История, История родного края...",
  "sources": [{"name": "Преподаватели", "url": "..."}],
  "session_id": "uuid-v4-string",
  "needs_clarification": false
}
```

## Структура данных

### Таблица `pages`
- `url`, `title`, `clean_text` — базовые поля
- `raw_html` — исходный HTML для переиндексации
- `content_hash` — для отслеживания изменений

### Таблица `fragments` (обогащённые)
- `text`, `content_type`, `position` — базовые поля
- `section_title` — заголовок текущей секции
- `parent_titles` — JSON: иерархия заголовков
- `specialty_code` — 54.02.01, 44.02.02, 40.02.04
- `academic_year` — 2026, 2027
- `document_type` — учебный план, программа, положение
- `metadata_quality` — low, medium, high

### Примеры данных

**Иерархия заголовков:**
```json
["Добро пожаловать на сайт колледжа «Номос»!", "Новости", "День учителя в «Номосе»"]
```

**Фрагмент с метаданными:**

## Ограничения

- **Не придумывает факты**: Использует ТОЛЬКО данные из индекса
- **Конфликты данных**: При противоречиях рекомендует связаться с приёмной комиссией
- **Кеш**: Инвалидируется автоматически при переиндексации
- **Контекст**: Ограничен ~32K токенов

## Архитектура

```
Клиент → HTTP Server → Answer Pipeline → SQLite / Ollama
         (rate limit)   (intent + search)   (index / LLM)
                              ↓
                        Enriched Metadata
                     (specialty, hierarchy, year)
```
