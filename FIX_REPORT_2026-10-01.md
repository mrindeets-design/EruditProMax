# Исправление проблемы: Бот выдаёт всё подряд вместо ответа на конкретный вопрос
**Дата:** 01.10.2026 21:35
**Проблема:** На вопрос "Какие специальности есть?" бот выдавал список специальностей + стоимость + директора + преподавателей

## Диагностика

**Симптомы:**
- Вопрос: "Какие специальности есть?"
- Ответ: список специальностей + стоимость каждой + директор + преподаватели
- Модель выгружала ВСЕ фрагменты RAG-контекста вместо синтеза ответа

**Причина:**
1. **Отсутствие явного запрета** добавлять непрошенную информацию в системном промпте
2. **Temperature 0.4** всё ещё давала механические/шаблонные ответы
3. **Инструкция "покажи полный список"** для специальностей была слишком общей
4. Модель воспринимала RAG-контекст как "что показать", а не как "откуда извлечь ответ"

## Решение

### 1. Добавлен критический блок в системный промпт (main.go, строка 1398)

```go
🎯 КРИТИЧЕСКИ ВАЖНО - ОТВЕЧАЙ ТОЛЬКО НА ЗАДАННЫЙ ВОПРОС:
❌ НЕ добавляй информацию, которую НЕ СПРАШИВАЛИ
❌ Если спросили список специальностей → НЕ добавляй стоимость, директора, преподавателей
❌ Если спросили про директора → НЕ добавляй преподавателей, специальности
❌ Если спросили стоимость → отвечай только про стоимость
✅ Читай вопрос внимательно и отвечай ТОЛЬКО на то, что спрашивают
```

**Эффект:** Явный запрет с примерами помогает модели понять границы ответа

### 2. Усилена инструкция для списка специальностей (main.go, строка 1487)

**Было:**
```go
- Покажи полный список всех специальностей из контекста
- Указывай полное название и код специальности
```

**Стало:**
```go
- Покажи ТОЛЬКО список специальностей (название + код)
- НЕ добавляй стоимость, директора, преподавателей, документы
- Просто перечисли 4 специальности — и всё
```

### 3. Повышена temperature: 0.4 → 0.5 (3 места)

**Локации:**
- `askOllama()` — main.go:1545
- `streamOllama()` — main.go:1624
- `streamFromOllama()` — main.go:2140

**Обоснование:**
- 0.3 давала роботизированные ответы
- 0.4 всё ещё была слишком консервативной
- 0.5 позволяет модели лучше интерпретировать намерение вопроса

### 4. Синхронизирован NEW_SYSTEM_PROMPT.txt

Добавлен тот же критический блок для консистентности документации.
