### 1. ✅ Исправлена личность бота

**Проблема:**  
Бот был слишком резким при ответе на вопросы, не связанные с колледжем.

**Решение:**  
Обновлён системный промпт для более дружелюбного и вежливого общения:

**Примеры новых ответов:**
- ❓ "Какая погода в Воронеже?"

- ❓ "Ты думаешь, что Земля плоская?"

  ✅ "Готовить я не умею, зато знаю всё про обучение дизайну и юриспруденции в «Номосе»! Чем помочь?"

### 2. ✅ Исправлена работа уточнений

**Проблема:**  
При уточнении бот начинал отвечать на другой вопрос и долго обрабатывал запрос.

**Решение:**  
- Сохранение темы (topic) при запросе уточнения
- Восстановление темы после ответа пользователя  
- Обработка уточнений только для коротких ответов (≤3 слова)
- Добавлено логирование для отладки

**Пример диалога:**
```
👤 Пользователь: "Сколько стоит обучение?"
🤖 Бот: "Уточните, пожалуйста, о какой специальности вы спрашиваете: дизайн, юриспруденция, преподавание в начальных классах или право?"
👤 Пользователь: "Дизайн"
🤖 Бот: "Обучение на специальности 54.02.01 Дизайн стоит 139 200 рублей в год."
```

## 🚀 Как использовать

### Запуск сервера:
```bash
cd c:\Users\Drago\Downloads\erudit
.\erudit.exe
```

Сервер запустится на `http://localhost:3000`

### Тестирование через curl:

**1. Офф-топик вопрос:**
```bash
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"Какая погода в Воронеже?\"}"
```

**2. Вопрос с уточнением:**
```bash
# Первый запрос
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"Сколько стоит обучение?\",\"session_id\":\"test123\"}"

# Уточнение (используем тот же session_id)
curl -X POST http://localhost:3000/api/chat \
  -H "Content-Type: application/json" \
  -d "{\"message\":\"Дизайн\",\"session_id\":\"test123\"}"
```
